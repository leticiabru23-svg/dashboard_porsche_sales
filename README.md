# 🏎️ Porsche Sales Dashboard

Dashboard interativo desenvolvido para **análise e visualização de dados de vendas da Porsche**.

O projeto apresenta informações comerciais de forma visual e intuitiva, permitindo analisar indicadores de vendas, desempenho e distribuição dos dados por meio de gráficos e métricas.

---

👉 **[Visualizar Dashboard Porsche Sales](https://leticiabru23-svg.github.io/dashboard_porsche_sales/)**

---

## 📊 Sobre o Projeto

O **Porsche Sales Dashboard** foi desenvolvido com o objetivo de transformar dados de vendas em informações visuais que facilitem a análise e a tomada de decisões.

A interface foi desenvolvida com o apoio de **Inteligência Artificial generativa**, utilizando o **ChatGPT** como ferramenta auxiliar durante o processo de criação, estruturação, revisão e aprimoramento do projeto.

---

## ✨ Funcionalidades

* 📈 Visualização de indicadores de vendas
* 🚗 Análise de modelos Porsche
* 💰 Acompanhamento de valores e desempenho comercial
* 📊 Gráficos para facilitar a interpretação dos dados
* 🎯 Organização dos principais KPIs
* 🖥️ Interface para visualização em navegador
* 🤖 Utilização de Inteligência Artificial como apoio ao desenvolvimento
* 🌐 Publicação utilizando GitHub Pages
